# Mystic Blog

基于 Next.js App Router、TypeScript、Tailwind CSS 和 MDX 的个人技术博客。

## 本地开发

```bash
npm install
npm run dev
```

访问 `http://localhost:3000`。

## 内容位置

- 博客文章：`content/posts/`
- 项目数据：`data/projects.ts`
- 个人与网站信息：`config/site.ts`
- 页面路由：`src/app/`
- UI 组件：`src/components/`
- 全局样式：`src/app/globals.css`

## 检查与构建

```bash
npm run lint
npm run build
```
